> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A friend opens `/game/<slug>`, types their name once, taps the globe per round, sees the reveal (distance, points, answer, photo, story), and lands on the game's leaderboard. Replays are blocked.

**Architecture:** New `src/game/scoring.js` (haversine + points, per spec). Public slug-scoped API in `src/game/routes.js`: game info WITHOUT secrets, a stateless per-round guess endpoint that returns the reveal, and a final submit that RECOMPUTES all points server-side and writes play+guesses in one transaction. `views/game/play.html` reuses the globe page's MapLibre patterns. Trust boundary: client totals are never trusted; the share link is the only access control (decided in the handover).

**Tech Stack:** better-sqlite3, Express router (existing), MapLibre GL 6.6.0 globe, node:test, localStorage for the player name.

```js
// Distance scoring for custom games (spec-pinned formula). Kept dependency-free
// so the whole game module stays liftable.
const rad = Math.PI / 180;

function haversineKm(lat1, lng1, lat2, lng2) {
  const dLat = (lat2 - lat1) * rad, dLng = (lng2 - lng1) * rad;
  const a = Math.sin(dLat / 2) ** 2
    + Math.cos(lat1 * rad) * Math.cos(lat2 * rad) * Math.sin(dLng / 2) ** 2;
  return 6371 * 2 * Math.atan2(Math.sqrt(a), Math.sqrt(1 - a));
}

// Full points within the round's tolerance radius, smooth decay beyond it.
function points(km, radius = 25) {
  return km <= radius ? 100 : Math.round(100 * Math.exp(-(km - radius) / 500));
}

module.exports = { haversineKm, points };
```

```js
const { haversineKm, points } = require('./scoring');

const validCoords = (lat, lng) =>
  Number.isFinite(lat) && Math.abs(lat) <= 90 && Number.isFinite(lng) && Math.abs(lng) <= 180;

  // ---- Public play API (the slug is the access control; scoring is server-side only). ----
  router.get('/api/:slug', (req, res) => {
    const g = db.getGameBySlug(req.params.slug);
    if (!g) return res.status(404).json({ error: 'no such game' });
    res.json({ title: g.game.title, rounds: g.rounds.map((r) => ({ ord: r.ord, question: r.question })) });
  });

  router.post('/api/:slug/guess', (req, res) => {
    const g = db.getGameBySlug(req.params.slug);
    if (!g) return res.status(404).json({ error: 'no such game' });
    const b = req.body || {};
    const round = g.rounds.find((r) => r.ord === b.ord);
    if (!round) return res.status(404).json({ error: 'no such round' });
    if (!validCoords(b.lat, b.lng)) return res.status(400).json({ error: 'bad coords' });
    const km = Math.round(haversineKm(b.lat, b.lng, round.lat, round.lng) * 10) / 10;
    const { question, ord, game_id, id, ...truth } = round;
    res.json({ km, points: points(km, round.radius ?? undefined), truth });
  });

  router.post('/api/:slug/plays', (req, res) => {
    const g = db.getGameBySlug(req.params.slug);
    if (!g) return res.status(404).json({ error: 'no such game' });
    const b = req.body || {};
    const name = typeof b.player_name === 'string' ? b.player_name.trim().slice(0, 40) : '';
    const guesses = Array.isArray(b.guesses) ? b.guesses : [];
    const byOrd = new Map(guesses.filter((x) => x && validCoords(x.lat, x.lng)).map((x) => [x.ord, x]));
    if (!name || g.rounds.some((r) => !byOrd.has(r.ord)) || byOrd.size !== g.rounds.length) {
      return res.status(400).json({ error: 'name and one valid guess per round required' });
    }
    const scored = g.rounds.map((r) => {
      const x = byOrd.get(r.ord);
      const km = Math.round(haversineKm(x.lat, x.lng, r.lat, r.lng) * 10) / 10;
      return { round_ord: r.ord, lat: x.lat, lng: x.lng, km, points: points(km, r.radius ?? undefined) };
    });
    const total = scored.reduce((s, x) => s + x.points, 0);
    try {
      db.recordPlay(g.game.id, name, total, scored);
    } catch (e) {
      if (String(e.code).startsWith('SQLITE_CONSTRAINT')) {
        return res.status(409).json({ error: 'already played', leaderboard: db.listPlays(g.game.id) });
      }
      throw e;
    }
    res.json({ total, rounds: scored, leaderboard: db.listPlays(g.game.id) });
  });

  router.get('/api/:slug/leaderboard', (req, res) => {
    const g = db.getGameBySlug(req.params.slug);
    if (!g) return res.status(404).json({ error: 'no such game' });
    res.json({ leaderboard: db.listPlays(g.game.id) });
  });
```

Behavior state machine:

```
load → GET /game/api/<slug from location.pathname>
  no name in localStorage('maptap:player') → name overlay; Play stores it
guessing(ord): map click → move guess marker; Confirm enabled once placed
  Confirm → POST guess → reveal(ord): truth dot + guess→truth line (geojson
  LineString), fitBounds(both, padding 80), reveal card; store {ord, lat, lng}
  Next → clear line/markers → guessing(ord+1) | after last → submit
submit → POST plays {player_name, guesses} → end screen with leaderboard
  409 → “<name> already played this one” + leaderboard
```

Implementation notes (all patterns exist in-repo): guess marker = `new maplibregl.Marker({ draggable: true })`, map click repositions it; the truth dot = small geojson circle layer added per reveal and removed on Next; the line = geojson source `reveal` updated per round; escape ALL server text via `textContent` (reveal card is built with createElement like globe.html's `openPanel`); photos `img.loading = 'lazy'`; expose `window.map` + `window.playState = { place(lat,lng), confirm(), next() }` as a debug/driver handle (three one-liners calling the same functions the buttons use — the screenshot driver needs them because raw map input can't be simulated through MapLibre's pointer pipeline).
